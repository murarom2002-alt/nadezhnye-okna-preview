# Стоковые фото — источники и лицензия

Все файлы — с Unsplash, бесплатная лицензия Unsplash (https://unsplash.com/license): можно использовать
на коммерческом сайте, указывать автора не обязательно. Скачаны 2026-11-26 уменьшенными версиями
с images.unsplash.com (поиск с фильтром «Free», без фото Unsplash+).

Это **сток, а не работы компании**. Фоны и иллюстрации к услугам и блокам (первая таблица) могут
остаться и на боевом. Фото галереи «Наши работы» (вторая таблица) — только для черновика: подписаны
«Фото-пример», помечены заглушкой в `src/content/site.ts` (их ловит `npm run content:check`) и до запуска заменяются фото заказчицы
(DESIGN.md → Do's and Don'ts). Когда заказчица пришлёт свои фото — заменить файлы на те же места.
